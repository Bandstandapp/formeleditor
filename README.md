# Formeleditor

Word-Add-in und Web-Editor für mathematische und physikalische Formeln in Satzqualität (MathLive-Eingabe, MathJax-Satz).

- Einrichtung auf dem Mac: [ANLEITUNG.md](ANLEITUNG.md)
- Web-Version: https://bandstandapp.github.io/formeleditor/editor.html
- Add-in-Seitenleiste: `taskpane.html` + `addin.js`, Beschreibung für Word: `manifest.xml`

`taskpane.html` und `editor.html` werden aus einer gemeinsamen Quelle erzeugt (Ordner `src/`, `python3 src/build.py .`).
